# Шаблон: перевод

Перевод панели — плагин `type: language` (решение В9): словарь строк хоста для языка лежит в
`i18n/host/<язык>.json` — плоский объект «ключ `раздел.имя` → строка», подстановки `{0}`, `{1}`.
`host` в манифесте — каким версиям словаря панели он подходит. Ключи берутся из `ui/src/copy/ru.ts` панели;
чего нет в словаре, показывается по-русски.

```sh
s2p new lang ../lang-fr --name Français              # id lang-<код>
cd ../lang-fr && s2p keygen -o dev && s2p build . --key dev.sec -o dist
```
